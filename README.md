# Book Structure in C

## Description

A C program that creates a `Book` structure with the title, author, and price. It reads and displays the details of one book.

## Concepts Used

* Structures in C
* Character arrays and floating-point values
* `scanf()` and `printf()`

## How to Run

```bash
gcc book.c -o book.exe
./book.exe
```

## Language

C
